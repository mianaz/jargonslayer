每一条用户能感知到的变化，按时间倒序排列。除非条目里写明具体平台，否则版本号同时覆盖网页版、macOS 桌面版、iOS 测试版和 Chrome 插件。发布下载在 GitHub releases；接下来打算做什么见「功能页」。

v0.7

v0.7.7

2026-08-04最新
  • 检查更新：设置里可手动查新版，后台每日静默核对；发现新版弹横幅，一键打开下载页（桌面版）。
  • 翻译断线看得见：翻译通道会议中途死掉也会亮「翻译失败」，不再只有全程零翻译才报；判定有 60 秒地板，短暂抖动不闪假警。
  • 长会性能：90 分钟会议尾段逐条重算全表的热点改为增量缓存。
  • 转录服务重连：闪断改指数退避（1 秒起步 30 秒封顶），掉帧计入诊断，连挂五轮弹提示且不放弃重试。
  • 定位刷新：文案转向捕获优先——双路收音是主角，术语卡片是实时辅助；「全本地」只在默认本地引擎下声明。
  • 修复：翻译准备超时残留子进程；历史会话切换后说话人计数串台；更新检查遇 GitHub 限流误记已检查。

v0.7.6

2026-08-04
  • 双路收音：麦克风+系统音频同时捕获，回声消除，自动区分「我/对方」（macOS 26+ 桌面版）。
  • 全新三步首次引导，演示一键直达。
  • 状态栏显示实际运行模式与隐私状态，手机端常驻。
  • 手机界面收纳与 ⋯ 折叠。
  • 设置文案口语化 + 主题色板预览。
  • 无障碍：屏幕阅读器播报、对话框焦点管理、更大触控目标。
  • 学习中心「开始复习」置顶。

v0.7.5

2026-08-02
  • 翻译不再无声死掉：启动握手失败一次就把整场会议的翻译通道锁死，只有开头一条提示，之后一片空白——同一天同样设置的另一场却正常出双语。现在通道自动重连，真恢复不了状态栏写「翻译失败」，不再装作还在工作。
  • 桌面版麦克风模式录到静音：桌面版系统识别走的是系统输出捕获，没有麦克风通路，选「麦克风」只是给输出捕获贴了个麦克风标签，什么都识别不出来。现在麦克风模式走本地模型；之前已存成错误配置的安装启动时自动修正。
  • 采集来源不会再被贴错标签：设置里的引擎卡片只写引擎不写配套音频来源，选「系统识别」时来源还显示「麦克风」，底栏声称麦克风在录，实际走的是系统音频捕获。
  • 识别提示词按会议领域分配：系统识别接受一组提示词来提高专业术语转录准确率，以前平均分给所有启用的词典包——一场生信报告大部分预算花在金融和日常词汇上。现在按当前会议领域加权，个人生词本也不再独占整个预算。这只提高已有词条被正确转录的概率，不等于新增词条。
  • 会议记录一键导出到 Obsidian 和 Notion。
  • 端口冲突提示改成人话：本地转录服务端口 8765/8766 被上次强退的残留进程或第二个 app 实例占着时，启动直接崩出一段 Python 报错；现在写明哪个端口、大概是什么进程、怎么结束它。
  • 术语校正：设置和首次运行教程不再把音频来源当识别引擎列，也不再写「本地 Whisper」——本地模型也跑 Parakeet。

v0.7.4

2026 年 8 月
  • 多义、按领域排序的释义：一个词有多种释义时，现在会按会议领域排序——讲癌症恶病质时 CAC 解释成 Cancer-Associated Cachexia，不再是获客成本；「IND … or NDA or BLA」里的 NDA 认成新药申请；机器学习语境里 PR 指 precision-recall，不是 Pull Request；领域不明时依然给出一版可用的解释。
  • 划词 lookup 重做：选中任意文字先查词典，命中的词典包和义项全部列出，不再只留一个赢家；真查不到时结合上下文解释并翻译；加入我的词典退到弹窗里的次要位置。
  • 引擎选择器按类型分组：本地 STT 模型 / 系统 STT 服务 / 第三方 STT 提供商三组替换掉原来的一份平铺列表；第三方服务没配 Key 也常驻显示，标注「已配置」或「未配置」。
  • 音频来源独立成控件：会议进行中也能随时切换，不再是开会前才能选的浮层；系统/App 音频现在写明：录的是对方的声音，不含你自己的麦克风。
  • 密钥收进一个分类：LLM 提供商、转录、翻译、说话人分离 token 等所有 API Key，现在都在同一个 设置 → 密钥 界面里，不再散落在五个不同的设置分区；存储位置和钥匙串托管方式不变。
  • 连接失败提示更好懂：网页版连不上自建转录服务时，现在给一句人话提示，以前甩的是开发者才看得懂的 socket 报错。

v0.7.3

2026-07-30修复列车
  • API 密钥按提供商隔离：以前切换 LLM 提供商，上一个提供商的 Key 可能被一并发到新提供商那边；现在每个提供商的 Key 各自隔离存储、自动迁移，仍托管在 macOS 钥匙串。
  • 说话人改名修复：改名后花名册和实时选择器以前会卡在旧名字，直到会议结束才刷新；现在改名立刻在两处生效。
  • 卡片上下文收紧：表达卡片引用的原句以前是整段 60 词左右的 ASR 长句，现在只截取命中词周围的那个分句。
  • 误判和释义修复：in the red 不再被 the red graph 这类短语带偏；内置释义里错发成字面 1. 的 mean 已经在源头修好，新增构建时的释义检查。
  • 会议领域推断更准：生物学讲座里的「thank you for your attention」不再生出 attention 卡片，机器学习讲座里 precision、recall 依旧正常触发。

v0.7.2

2026-07-28修复列车
  • 词典匹配修复：以括号限定结尾的词条——stochastic gradient descent (SGD)、mode (statistics)——现在能在转录里正确命中（之前从未匹配过）；只启用专业词典包（比如生信、统计）时不再悄悄丢失和其他包撞名的词条，每个启用的包都会显示自己的释义；已安装的词典包和内置词典包撞名时，现在优先显示已安装包的释义。
  • Beta 反馈诊断增强：设置里「诊断信息」的日志查看器现在覆盖全部三个本地日志（Whisper 服务 / 系统/App 音频 / 系统识别），可以选择查看哪一个；新增「导出诊断文件」按钮把诊断信息包存成文件（iOS 上会打开系统分享面板）；Chrome 插件侧边栏首次获得「复制诊断」按钮。
  • 本地日志不再可能带上会议原声：桌面版语音识别日志写入逻辑的一处加固修复，堵上了最后一条畸形行可能泄漏原始语音的路径。
  • Chrome 插件升级到 0.7.2：带上了上面的词典可靠性修复；此前版本停留在 0.6.0。

v0.7.1

2026-07-28
  • 有道翻译引擎（BYOK）：翻译引擎又添一项——除了 LLM、平台自带的本机翻译和 DeepL，还能选有道，自备应用ID/应用密钥，按量计费；只在原生 App（桌面版/iOS）可用，网页版因有道 API 不支持跨域而不提供。
  • 会后补全翻译：会议结束后，工具栏一键把没翻译成功的片段用当前配置的翻译引擎补齐。
  • 导出跟随翻译：Markdown、docx、复制纪要导出现在带上已有的翻译，不再只认 AI 报告顺带生成的那份；还有没翻译的片段会先问你要不要补全后再导出，剩下的原地标出「未翻译」。
  • 存词改进：加入我的词典时记下这个词在会议里实际出现的形式，不只是词典的标准写法。
  • 手机端 UI 打磨：手机宽度下头部收成单行、状态芯片改回完整词而不是缩写、控件尺寸统一。
  • Bit 焕新：状态栏吉祥物重画了身体、换了更暖的配色，出场动画改成打招呼式。
  • 修复：展开的表达卡片里，原文例句不再被截断在两行。
  • iOS 修复：导出（Markdown、docx、备份、康奈尔笔记）改走系统分享面板——之前在 iOS 上点导出没有任何反应。

v0.6

v0.6.0

2026-07-24
  • 词典包扩展——17 包、上千词条：内置词典扩充到 17 个主题包，多义词按会议语境排序；新增变体匹配（85 条），能识别词条的屈折变化和近似形式——词典收录的是 get the ball rolling，说话人说成 keep the ball rolling 同样命中。
  • Apple 系统翻译扩展到 iOS：原先仅桌面版可用的 Apple 翻译引擎，现在也跑在 iOS 26+ 上——完全本机处理，不需要 API Key，文本不出设备。
  • iOS 版进入 TestFlight 内测：JargonSlayer 的 iOS 版现已通过 TestFlight 开放内测（受邀制，iOS 26+），系统语音识别和 Apple 翻译都在手机本地运行。
  • 手机主界面重构：转录占满手机主屏，解释卡片收进底部一条可左右滑动的卡片条——最新卡在最左，点转录里的高亮词直接跳到对应卡片。
  • 词典模式成为默认：新安装默认进入词典模式（始终开启、完全离线的检测底座）；AI 模式转为可选的 Beta。
  • 0.6.1 / 0.6.2 后续修复：iOS 版本号显示在标题栏；Apple 系统翻译覆盖到桌面版和 iOS 版所有适用的界面。

v0.5.0

2026-07-20
  • 模式优先 UI：会前先选「怎么听」（麦克风 / 标签页音频 / 系统/App 音频 / 导入文件）而不是先挑引擎，应用按平台和配置自动匹配对应引擎；新手引导同步重写。
  • 说话人工具：单句/批量指定说话人、「应用到本句及之后」、实时「当前说话人」标记；手动指定的句子会被锁定，不会被后续自动说话人分离覆盖。
  • AI 转写修订（审阅制）：会后一键通读转录、挑出识别错误，逐段列出原文与修正建议，接受才生效；接受后自动重新翻译。
  • 崩溃恢复：会议实时写自动草稿，页面刷新或浏览器崩溃后，历史里一键「恢复到历史记录」。
  • 划词解释后台生成：选中文本的解释在后台完成、自动并入卡片列表，关掉弹窗也不会丢。
  • 导出与联动：新增 docx 导出；AnkiConnect 一键把生词卡同步进本地 Anki（自动去重）；个人词典可拆成多个自定义命名词包。
  • 翻译引擎可选：双语字幕和全文翻译默认用 LLM，Chrome 138+ 可切到浏览器内置的本地翻译（免 Key）；桌面版和 iOS 版现在还能选 Apple 系统翻译（macOS 26+ / iOS 26+），同样本机运行、免 Key。
  • Deepgram 云端识别（BYOK，英文）：新增一个纯英文场景的云端识别引擎选项。
  • 在线体验的限量试用：内置 Soniox 云端识别限量试用（免 Key，每人每天最多 3 段、单次最长约 10 分钟，总额度先到先得）；标签页音频回归在线体验，走同一试用额度。

v0.4 系列

v0.4.0 – v0.4.6

2026-07-12 → 2026-07-19
  • 桌面版（Tauri，macOS，v0.4.0）：应用自己托管本地 Whisper——需要用户同意才继续安装的向导、模型选择器加实时切换模型、说话人分离扩展一键安装。签名并公证的 DMG 在 releases 页面。
  • 设备端浏览器识别：Chrome 139+ 优先本地识别，云端自动兜底。
  • Soniox 实时引擎（实验，自备 Key）：面向中英夹杂场景；通过内部基准测试前保持「实验」标记。
  • 系统/App 音频（桌面版，macOS 14.4+）：基于 CoreAudio process tap，捕获这台 Mac 正在播放的声音，替换了桌面版旧版的标签页音频。
  • 系统识别（桌面版，macOS 26+，v0.4.3）：基于 macOS 原生 SpeechAnalyzer 的零安装引擎——不下载模型、不装 Python，音频不出捕获进程。
  • 英文加速（桌面版，Apple 芯片，v0.4.4）：模型选择器里的可选引擎（非默认）——比 Whisper 快得多（批量推理约百倍实时），暂不支持实时说话人分离。
  • Chrome 插件（Lite）：MV3 侧边栏，含实时麦克风捕获、内置词典、设备端翻译。
  • 桌面版外壳功能：后台任务中心、状态栏里的引擎下拉菜单、首次引导（OpenRouter OAuth + 说话人分离 token），以及发布更新检查。
  • AI 透明面板 + 领域词典包（v0.4.6）：按任务的 AI 状态面板（检测/解释/翻译/报告），显示模型、路由方式和调用/失败/QC 丢弃次数，外加状态栏小标；三个新内置词典包——统计学、机器学习、生物信息学（约 226 个术语）；以及一处检测质量修复，普通句子不再被误判成黑话。
